## The entry

A single line (133 characters) roasting a smart fridge: it needs a software update to make ice, Wi-Fi to stay cold, and a $4.99 subscription just to tell you the milk died yesterday. Three escalating absurdities, one punchline — specific to smart fridges (firmware, Wi-Fi, subscription, milk), and it dodges the obvious cracks about ordering groceries or watching you.

## How to run

Requires Node 22.18 or later (runs TypeScript as-is, no dependencies to install):

```sh
node main.ts
```

This writes the roast to `/output/entry.txt` (1–200 characters, single line, UTF-8), with a built-in self-check that rejects anything outside the limit.
